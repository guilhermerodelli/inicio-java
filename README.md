# 🚀 Projeto Início Java

Esse repositório contém um projeto de **aprendizado em Java** com foco nos primeiros passos, lógica de programação e estrutura básica de classes em Java.

Este projeto foi criado como parte do meu processo de estudo para reforçar conceitos fundamentais da linguagem e aplicar práticas básicas.

## 🛠 Tecnologias Utilizadas

O projeto foi desenvolvido usando:

- 🧠 **Java**
- 📦 Estruturas de classes e métodos
- 🖥️ Interação via console

Este projeto inclui:
